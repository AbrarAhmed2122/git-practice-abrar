# Project Description

## Objective
The objective of this project is to practice Git version control and GitHub repository management.

## Features
- Display the student's name and current date
- Add two numbers
- Subtract two numbers
- Multiply two numbers

## Development Workflow
The project uses Git commits to record changes, feature branches to develop new functionality, and merges to integrate completed features into the main branch.

## Tools Used
- Python
- Git
- GitHub
